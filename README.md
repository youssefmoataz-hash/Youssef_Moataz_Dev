# Youssef Moataz — Portfolio

Single-page responsive portfolio for GitHub Pages.

## Files
- `index.html` — portfolio structure
- `style.css` — responsive dark/neon design
- `script.js` — navigation + contact form
- `assets/profile.jpg` — profile image

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your live portfolio URL.

No CV button is included.
